## 2. Reflection styles (model-written only with rig evidence)

Goal: let the user pick how a reflection reads (the "custom AI personas" idea from CLAUDE.md Phase 3, scoped as styles).

Order, from no invention risk to most:
1. **App-composed styles, no model change.** Fixed wording around the same verbatim quote (for example gentle / direct / curious), built from `groundedLocales`-style strings in all 10 languages. Grounded by construction. No rig needed for wording alone, but translations need the i18n kit.
2. **Model-written styles.** Only if a rig round matches today's numbers (FM English shown PASS about 98%; Gemma grounded quote plus one feeling sentence). Write the rubric first, N >= 10 per style per engine, then decide. Candidate surfaces: FM `@Guide` text per style, Gemma grammar per style.
3. Anything that loosens the Gemma grammar to free prose is out (measured about 0/40 faithful).

Deliverables: a design note (which styles, where the picker lives, how "How this was generated" describes the style), the rig rubric, rig results in `tools/llmrig/`, then the build. Settings or a standalone surface; do not gate on entry state or add CloudKit schema unless asked (owner preference).

Settled, do not reopen without new evidence: longer FM reflection (V1f failed round 10), extra app-built lines such as mood trend, theme or streak (owner declined; only the second quote shipped).

## 3. Write view: improvements and fixes (UI and UX), the main focus

Files: `Features/Write/WriteView*.swift` and the editor (`NoteEditorTextView` on iOS, the `NSTextView` editor on Mac). Check Classic and Sentinel themes for every change (`@Environment(\.appDisplayMode)`).

Method: audit first, fix in small commits, one test or capture per fix.
1. **Audit pass** (no behavior change): run the editor quality checklist (paste, lists, undo/redo, IME, selection, 10k and 50k characters, dictation, photos, voice, scan), list defects with a reproduction, and rank them.
2. **Fix pass** from that list. Known candidates to confirm in the audit: keyboard and toolbar overlap, draft-safety messaging, Notes-style formatting on iOS to match Mac, scroll and caret behavior while typing, accessibility (Dynamic Type, VoiceOver labels), Sentinel versus Classic divergence, iPad and Mac layout.
3. **UX pass:** capture speed (open to typing), mood and tag entry, date and collection picker clarity, save feedback, error states.
4. **Verification:** unit tests where logic moves, UI tests for flows, screenshots in both themes, a device run on the iPhone 14 Pro for anything touching keyboard or gestures [owner].

Findings and fixes are tracked in `3.1.0-write-view-audit.md` (created when the audit starts).

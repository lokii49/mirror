# 3.0.7 roadmap

Branch `3.0.7` from `main` at `78f9d69` (3.0.6 build 12 is in App Store review, auto-release).
Version and build are still 3.0.6 / 12: bump before the first shipping commit.

## Planned

1. **Onboarding word count for ja/zh.** `OnboardingFlow.swift` split the first entry on single
   spaces, so a Japanese/Chinese line showed "1 word". Use `segmentedWordCount`.
2. **CJK recount waits for CloudKit.** `CJKWordCountRecount` could mark itself done on a new device
   before ja/zh entries finished syncing. Gate it on the first backgrounding, like
   `UngroundedInsightCleanup` and `PreGrammarInsightRegrade`.
3. **Rotate the reflection openers.** Every Gemma reflection opens `You wrote, "…"`. Rotate a few
   fixed openers the app writes itself (e.g. "In your words,"), so the model never writes them.
   Careful: `groundedNudgePrefix` and each locale's `youWrote + open` are detection anchors
   (`isGrammarGrounded`, `nudgeTextForOutsideApp`, `moodOfQuotedEntry`, the grammar, saved rows).
   Every new opener must be recognised everywhere the old one is, and the old one must stay
   recognised for rows already saved. Measure on the rig before shipping.
4. **Follow-up strings in the i18n review kit.** Add `pickFollowUp` / `partsLabel` /
   `followUpQuestion` to `tools/i18n/review` (`build_data.py`, `build_md.py`, `template.html`), then
   republish the review page.

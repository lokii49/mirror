# 3.1.4: Recently Deleted, Drafts, Duplicates, collection picker in Write

Branch `3.1.4` (from 3.1.3 `e0345af`). Commit only, no push. Owner decisions 2026-10-18:
trash syncs via iCloud; saved drafts stay on the device; a duplicate is the same text (any date);
all four are Free tier.

## 1. Recently Deleted (synced)

- Deleting an entry moves it to a `TrashedEntry` row and deletes the `Entry`. No flag on `Entry`:
  29 `@Query` + 48 `FetchDescriptor<Entry>` sites (insights, Ask, widgets, alerts, Brain) would
  each need a filter, and 3.1.3 / Mac 1.1.3 clients would show trashed entries as live.
- `TrashedEntry` copies every stored `Entry` field **verbatim (ciphertext)**, so an entry this
  device can't decrypt can still be trashed and restored without re-encryption. A test compares
  the two schemas' property names so a new `Entry` field can't be forgotten.
- Restore inserts `Entry` with the original id (JournalSafety's insert hook forgets the backup
  "user deleted" mark) and deletes every trash row for that id. If the entry already exists
  (restored on another device), the trash row is just removed.
- Auto-purge after 30 days, on app-active and the nightly pass. Empty Trash / Delete Now
  remove rows for good. Delete Everything removes trash rows too.
- **CloudKit: new record type `CD_TrashedEntry`.** Run `--seedCloudKitSchema` on a sim signed into
  iCloud, then Deploy Schema Changes in CloudKit Console **before any TestFlight/App Store build.**

## 2. Collection picker in Write

- Chip at the start of the tags row (iOS) / button in the Mac toolbar: Unfiled, each collection,
  New collection…. Own view with its own `@Query`; nothing added to `WriteView.body`'s modifiers.
- Saved on new and edited entries; kept in new-entry and edit drafts (`Payload.collectionID`,
  optional, old drafts decode without it).

## 3. Drafts (device only)

- Write bar (owner pick 2026-10-18): trash, then a Drafts menu as a `doc.text` icon with a count
  badge (an icon, not the word, so it moves to the Duo's vertical strip with the trash): Save to
  Drafts, the 3 newest drafts to continue, All Drafts…. Mac: a tray menu in the toolbar.
- "Save to Drafts" on a new entry moves the editor's draft (text blob + attachment file, still
  sealed) into a saved slot `mirror.writeDraft.v2.saved.<id>` and clears the editor.
- Drafts list (Entries > Saved views menu, and Organize): Continue writing, Delete, Delete All.
  Continue is done by the main Write editor itself: anything it holds goes to Drafts first, then
  the chosen draft becomes the editor's draft. Nothing is overwritten.
- Delete Everything clears saved drafts.

## 4. Duplicates

- Same text after trimming and collapsing whitespace, any date. Empty-text and unreadable entries
  never match, nor do texts under 5 words ("Tired." on five days stays five entries). Each entry's
  date is shown; groups over several days say "Written on different days."; merge is per group. 
- Merge keeps the oldest, adds the others' tags and voice notes it doesn't already have
  (byte-equal), their photos only when it has none (photos are placed by index in the text), a mood
  if it has none, and moves the others to Recently Deleted (so a merge can be undone there).

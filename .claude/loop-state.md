## Backlog

Seed source: SwiftUI `var body`/computed properties doing per-frame `.sorted`/`.filter`/`Dictionary(grouping:)`
work with no `.task`-cached equivalent (same bug shape as the fixes already benchmarked in
`mirrorTests/PerformanceXCTests.swift`). Re-scan `Features/**/*.swift` for this pattern before assuming the list below is complete.
Lesson from Log [10]: the grep for `.sorted(`/`.filter { }`/`Dictionary(grouping:`/`decrypt` is not
sufficient on its own — a hand-written `for` loop doing the equivalent work (dedup, streak-walk,
front-scan) won't match those keywords. Files that already have ONE `.task(id:)` cache are not safe
to skip: check every computed property in the file, not just the ones the grep flagged, especially
if a sibling property reads the same full-history `@Query` uncached (see `MoodTimelineView.swift`,
which cached its heatmap chain in Log [1] but missed `currentStreak`/`consecutiveNegativeCount`
right below it).

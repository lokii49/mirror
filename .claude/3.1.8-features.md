## Rules every item follows
- App-built only. No model writes new text (no llmrig round in this plan). Nothing invents.
- Anything that reads entries for an insight, mood aggregate or model call goes through `InsightScope`
  (`InsightEntriesMemo` in views, `InsightScope(context:)` in runners). Kept-out entries still count as writing.
- Standalone surfaces (own sheet/page/entry point). No new WriteView body modifiers (stack limit; split views).
- No new CloudKit record types or fields (deploy gate). Per-device data in UserDefaults/app files; synced data
  only inside existing encrypted payloads or entry text markers.
- Both themes (default + Sentinel) where a themed view is touched; iOS and Mac both, unless the item says why not.
- Strings: Localizable.xcstrings in 9 languages, model-translated, `needs_review`, Xcode JSON layout.
- Never log journal text. Synthetic text only in tests and fixtures.
- Tests: unit (Swift Testing) on the 14 Pro via `tools/testing/prepare_search_device.py` copy; throwaway XCUITest
  for UI; Mac via the devmac harness (`--macSnapshot…Only` modes, adhoc.xcconfig). Build iOS + Mac before commit.
- Audit at the end: `/code-review` per item set + one whole-round review; full mirrorTests on device in groups.
